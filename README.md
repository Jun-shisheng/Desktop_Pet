# Desktop_Pet · DeepSeek 大肥鱼桌宠

一个 Windows 桌面宠物程序（C# / WPF，.NET 10，自包含单文件发布）。
主角是爱吃白饭的蓝色大肥鱼，灵感来自 DeepSeek 鲸鱼的社区形象。

> ## 项目状态
>
> **当前版本：单桌宠的简易互动与小游戏。**
> 一只大肥鱼住在桌面上，会自己走动、睡觉、钓鱼、看书、喝茶，吃你的桌面图标，
> 还能陪你玩「图标跳一跳」和「窗口打地鼠」两款小游戏。
>
> **正在开发：多名桌宠之间的互动与游戏。**
> 目标是让多只桌宠同时生活在桌面上，彼此打招呼、结伴行动、互相玩耍，
> 并共用一套游戏规则。仓库描述里的「提供多名桌宠的互动平台」就是这个方向。
>
> 现阶段代码里已经为多桌宠预留了接口：DeepSeek 状态快照会同时读取
> `%LOCALAPPDATA%\DeepSeekFishPet\` 和 `%LOCALAPPDATA%\CrossPet\` 两个目录，
> 行为引擎（`Behavior/PetBrain.cs`）也把「动作」与「状态机」分开，
> 便于把单只桌宠的决策扩展到多只之间协商。

## 现在能做什么

### 单只桌宠的日常互动

| 互动 | 说明 |
| --- | --- |
| 摸头 / 欢呼 | 单击摸头，双击欢呼 |
| 拎起来 | 按住左键拖动，把她拎到屏幕任意位置 |
| 晃一晃 | 拎起来左右来回晃动后松手，一次吐出所有已吃下的图标 |
| 站到图标上 | 把角色拖到桌面图标上松手，她会站上去走动；顶行图标只能从侧面攀附 |
| 站在窗口上 | 拖到窗口顶边，或从上方落到顶边，她会站在窗口上；走出边缘就自由落体 |
| 窗口探头 | 默认每隔约 2～4 分钟，从一个可见窗口的边缘悄悄探出脑袋；点一下她就躲起来 |
| 吃图标 | 饿了会靠近桌面图标并「吃」掉它，约 10～14 秒后消化完继续活动 |
| 自主生活 | 走动、奔跑、攀爬、打盹、钓鱼、看书、喝茶、舀白饭……共 **89 个状态** |

角色素材是 **23 张**透明姿态图（`assets/characters/whale/`），
配合位移、转向、缩放和道具效果组成动画。

### 两款小游戏

- **图标跳一跳** —— 把**当前可见的桌面图标**当作跳台，在图标之间跳、攀爬、挂边缘；
  前方没路了就等你用真实快捷方式搭桥，还会折纸飞机飞过远距离的图标。
- **窗口打地鼠（60 秒）** —— 从可见窗口的边缘探头，点中得分，60 秒一局。

### 路线图

| 阶段 | 状态 | 内容 |
| --- | --- | --- |
| 单桌宠互动 | ✅ 已完成 | 生活模式、桌面图标互动、窗口互动 |
| 单桌宠小游戏 | ✅ 已完成 | 图标跳一跳、窗口打地鼠 |
| **多桌宠互动** | 🚧 **开发中** | 多只桌宠同时在场、互相打招呼 / 结伴 / 玩耍 |
| 多桌宠游戏 | 📋 计划中 | 桌宠之间的对战与协作玩法 |

## 三种模式

### 生活模式

大肥鱼会自主走动、休息、打盹、钓鱼、看书、喝茶，右键菜单也能立即触发这些动作。
自主行走会保持朝向，走到桌面边缘才转身；站着时不会周期性地左右摆动。
行为引擎定义了 89 个状态，涵盖行走、奔跑、攀爬、跳跃、舀白饭、挥鳍、睡眠、钓鱼、
阅读，以及与桌面图标的互动。

**吃图标**：饿了会靠近桌面图标。吞下时，程序按 Windows 返回的图标和文字实际范围
临时遮住桌面上的对应图标，遮住的位置也暂时不能点击。吃撑约 10～14 秒后消化完继续活动，
之后还会再饿、再吃其他图标；先前吃下的图标仍留在肚子里。随时拎起来回晃动都能一次吐出
全部图标，分身会飞回各自当前位置，遮罩随后撤去。退出程序时，所有尚未吐出的图标也会
立即恢复显示。**快捷方式文件和位置始终保留。**

**窗口探头**：默认每隔约 2～4 分钟悄悄从一个可见、未最大化的应用窗口边缘探头。
单击它就会躲起来，过一会儿继续日常活动；窗口移动时它会跟着边缘移动。
这个偶发互动不计分，独立于「窗口打地鼠」模式，可以在菜单里关掉。

### 图标跳一跳

通过菜单选择「图标跳一跳」后，把大肥鱼拖到图标上松开也能从该位置继续游戏。
程序读取**当前可见桌面图标的位置**，把它们当作跳台。有空间时，大肥鱼的脚底对准图标上沿；
顶行图标上方空间不足时，它会攀附在图标旁。它会在图标之间跳动，偶尔攀爬、挂住边缘或
停下来观察。

前方没有可达图标时它会等待；你可以自己在 Windows 桌面上拖动真实快捷方式搭桥，
布局刷新后它会尝试继续。等待约 30 秒仍没有桥，或进入模式后一直没有可用图标，
都会退出小游戏回到生活模式。遇到距离更远、但高低差合适的图标时，它可能折出纸飞机飞过去。

> 这个模式不会触发吃图标。移动真实快捷方式的决定与操作都由你在 Windows 桌面完成；
> 程序只读取它们的位置。

### 窗口打地鼠

通过菜单选择「窗口打地鼠（60 秒）」开始一局。大肥鱼会从当前可见、未最大化的普通应用
窗口边缘探头；点中脑袋可得分，没点中则计一次漏掉。它会跟随窗口移动或改变大小；
如果窗口不再适合游戏，会换一个窗口。探头下方与菜单可查看当前命中数和剩余时间。
时间结束后返回生活模式。

全屏窗口、最大化窗口和桌面本身不会作为探头位置。

## 运行与操作

把发布包解压到任意可写目录，双击 `DeepSeekFishPet.exe`。
无需安装程序，也无需单独安装 .NET 运行时。右键角色或系统托盘里的大肥鱼图标打开中文菜单，
切换模式、指定动作或退出。程序会在可执行文件旁保存 `settings.json`；
若目录只读，本次运行仍可使用，设置只在本次会话内生效。

| 操作 | 效果 |
| --- | --- |
| 单击角色 | 生活模式摸头；图标跳一跳模式催她继续跳 |
| 双击角色 | 生活模式欢呼；图标跳一跳模式催她继续跳 |
| 按住左键拖动 | 拎起角色并移动 |
| 把角色拖到桌面图标上松开 | 生活模式留在图标上；图标跳一跳模式从该图标继续游戏。顶行图标可攀附 |
| 生活模式中拎起角色来回晃动后松开 | 一次吐出所有已吃下的图标；消化后也能这样操作 |
| 生活模式中单击从窗口边缘探出的脑袋 | 大肥鱼藏起来，随后恢复日常活动 |
| 窗口打地鼠时单击探出的脑袋 | 击中并加分，大肥鱼稍后从另一个窗口边缘出现 |
| 右键角色或托盘图标 | 打开模式、动作和设置菜单 |
| 托盘菜单「移回主屏幕」 | 找不到角色时将她带回主屏幕 |

菜单里可以开关：暂停活动、平时置顶、显示对话气泡、跟随 DeepSeek 工作状态、
显示 DeepSeek 余额、允许快捷方式分身互动、偶尔从窗口边缘探头。

## 构建

需要 Windows 和 **.NET 10 SDK**。在项目目录打开 PowerShell：

```powershell
.\build-portable.ps1
```

输出：

- `dist/DeepSeekFishPet-win-x64/` —— 自包含单文件发布目录
- `dist/DeepSeekFishPet-win-x64.zip` —— 便携压缩包

目标电脑是 Windows ARM64 时：

```powershell
.\build-portable.ps1 -Runtime win-arm64
```

日常开发调试也可以直接：

```powershell
dotnet build
dotnet run
```

> 姿态图以 `EmbeddedResource` 形式打进程序集（见 `DeepSeekFishPet.csproj`），
> 因此发布包只需要一个 exe。

## 安全边界

**图标跳台的位置**通过 Windows Shell 的桌面视图接口**只读**获取。
吃图标时，程序按 Explorer 中该图标和文字的实际绘制范围覆盖壁纸画面，吐出时撤去覆盖；
动画中移动的是同一图标的 Shell 图像。Windows 没有受支持的单个桌面图标临时隐藏接口，
因此 Explorer 中的原项目并未被删除或改变属性。

程序**不会**移动、重排、重命名、打开或删除真实桌面图标及快捷方式。
无法读取壁纸时，本次吞吃会取消；动态壁纸或某些系统视觉效果下，遮罩可能与背景有色差。
窗口打地鼠只读取窗口的可见状态与位置，**不会移动或激活被选中的应用窗口**。

若出现「暂时盖不住这个图标」，程序会在
`%LOCALAPPDATA%\DeepSeekFishPet\diagnostics.log` 记录失败阶段、窗口句柄与坐标，方便定位；
**日志不记录图标名称或文件路径。**

## DeepSeek 联动（可选）

`Integrations/DeepSeekHarness/` 是一个可选的 DeepSeek Harness 插件，
让大肥鱼跟着你的工作状态做表情，并显示账户余额：

```
listening → 大肥鱼认真听你说…      thinking  → 大肥鱼正在想办法…
writing   → 大肥鱼正忙着写…        reading   → 大肥鱼翻翻资料…
Stop      → 大肥鱼干完活啦！        asking    → 大肥鱼等你回答呢…
```

安装（**请在 Harness 关闭时运行**）：

```powershell
.\Integrations\DeepSeekHarness\install.ps1 -ProfileDirectory "$HOME\.dsh\profiles\web"
```

每个被修改的配置文件都会留下带时间戳的备份。卸载加 `-Uninstall`。

桌宠侧只**只读**读取插件写下的 JSON 快照（`deepseek-state.json` /
`deepseek-quota.json`），不会启动或配置 Harness，也不会写对方的状态目录。
快照只有姿态、事件、工具名和时间戳，**不包含对话内容或密钥**。
不装这个插件也不影响桌宠的所有功能。
