# 大肥鱼桌宠素材制作规范（whale_v2）

## 方向

用户提供的桌宠截图只用于判断**屏幕显示大小与细节密度**：小尺寸仍要看清表情、轮廓和动作道具。人物继续使用项目自己的蓝发鲸鱼女仆设定；不临摹截图中的角色、服饰或图标。

统一形象以本目录的 `idle.png` 为准：大圆脸、小短身、蓝色渐变长发、青蓝色大眼睛、白色女仆头箍、深蓝蝴蝶结上的小鲸鱼发饰、两侧鲸鳍状发束、深蓝与白色荷叶边衣裙、围裙鲸鱼徽记，以及**单条**蓝色鲸尾。白饭是角色主题：`idle` 的饭碗、`attack` 的白饭勺及进食动作要清楚；其他动作无需硬加饭碗，但人物特征必须一致。

## 技术规格与验收

- 每张为 **1254×1254 PNG、RGBA 真透明背景**；画布中只放人物与该动作必要的道具，不画场景、地面、投影、文字或水印。避免透明边缘的白边、黑边和硬裁切。
- 保持一致的头身比例、脸型、眼睛、发色、衣裙、发饰和鲸尾形状；用干净的深蓝粗轮廓及清晰色块，少用缩小后会糊成一团的细线。站立动作的鞋底尽量落在同一基线；坐姿、睡姿、探头和纸飞机按动作需要调整，仍要留适当透明边距。
- 在实际桌宠约 **180 px** 显示尺寸验收普通姿态，在约 **100 px** 验收 `peek.png`：一眼能认出大肥鱼、表情和主要道具。书、茶杯、钓竿、白饭勺、纸飞机等道具优先保留清楚的外形。
- 逐张检查 alpha、方形尺寸、主体是否完整、是否只有一条鲸尾，以及动作之间人物面部与服装是否漂移。`peek.png` 是用于窗口边缘的小型探头素材，可只露头和上半身。

## 文件与动作

文件名保持与程序素材键一致，共 **24 张**：

| 文件 | 动作与关键道具 |
| --- | --- |
| `idle.png` | 日常站立，端白饭碗、筷子，作为人物风格锚点 |
| `walk.png` | 朝前行走，鞋底基线稳定 |
| `walk_alt.png` | 另一行走步相，与 `walk` 衔接 |
| `run.png` | 奔跑，头发与鲸尾顺动作摆动 |
| `run_alt.png` | 另一奔跑步相，与 `run` 交替播放 |
| `jump.png` | 起跳或腾空，动作方向清楚 |
| `sit.png` | 坐下休息 |
| `sleep.png` | 安静打盹，闭眼 |
| `sleep_blanket.png` | 盖浅蓝鲸鱼花纹被子熟睡 |
| `read.png` | 坐着读一本明显打开的书 |
| `tea.png` | 双手捧茶杯喝茶 |
| `fish.png` | 坐着持钓竿，线与钩可辨 |
| `nibble.png` | 准备小口进食，双手留空供程序叠加实际图标 |
| `stuffed.png` | 吃饱后的满足姿态 |

## 制作方式

使用**内置 imagegen**，每个文件单独生成，要求透明背景。以 `idle.png` 作为**人物与画风锚点**，以旧版同名图作为**动作与道具参考**，明确两张图各自的用途。完成逐张检查后，24 张新版图已集成到 `whale/`；旧版保存在 `whale_backup/`。
